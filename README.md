# Cursor-CoPilot-AI-UI

A minimal design system and AI UX guardrails built for Cursor/Copilot workflows. Provides atomic tokens, base components, and automated QA to help teams build consistent, client-ready UIs at speed.

## Quick Start

1. Open `index.html` in a browser to see the functional UI demo
2. Review `DESIGN_SYSTEM.md` for complete documentation
3. Use the design tokens in `design-tokens.css` for all styling
4. Build UIs with base components from `components.css`

## Features

- **Design Tokens**: Atomic design values for typography, spacing, and colors
- **Base Components**: Reusable UI building blocks (buttons, inputs, cards, typography)
- **Functional UI**: Complete demo page showcasing all components
- **Comprehensive Documentation**: Full design system reference

## Files

- `design-tokens.css` - Core design token definitions
- `components.css` - Base component styles
- `index.html` - Functional UI demonstration
- `DESIGN_SYSTEM.md` - Complete documentation

## Design Principles

- Use only defined design tokens (no custom values)
- Follow 8px spacing grid system
- Maintain consistent typography hierarchy
- Prioritize clarity and usability
- Build with base components only
